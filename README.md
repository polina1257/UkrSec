# Економічна безпека України — сайт-візитівка

Статичний адаптивний сайт із двох сторінок: профіль авторки та мініаналіз економічної безпеки України у 2014–2026 роках.

## Файли

- `index.html` — сторінка «Про авторку».
- `analysis.html` — аналіз економічної безпеки України.
- `styles.css` — стилі та адаптивне компонування.
- `script.js` — мобільне меню та SVG-графіки без додаткових бібліотек.

## Перегляд

Відкрийте `index.html` у браузері. Для графіків не потрібне інтернет-з’єднання. Шрифт завантажується з Google Fonts, а за відсутності мережі використовуються системні шрифти.

## Публікація на GitHub Pages

1. Створіть публічний репозиторій GitHub.
2. Завантажте чотири файли цього набору в корінь репозиторію.
3. У репозиторії відкрийте **Settings → Pages**.
4. У полі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`, потім натисніть **Save**.
5. Після публікації сторінка автора буде за адресою репозиторію, а сторінка аналізу — `/analysis.html`.

## Джерела та статистичні примітки

Основні джерела й методологічні застереження наведено на сторінці `analysis.html`. Значення ВВП і інфляції округлені. Показники за 2026 рік є прогнозами МВФ (липень/жовтень 2026), не фактичними підсумками року. Оцінка боргу 98,4% ВВП за 2025 рік — попередній розрахунок Міністерства фінансів України. Не порівнюйте її напряму з прогнозом загального державного боргу МВФ за іншою методикою.
